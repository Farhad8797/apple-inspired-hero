# Simple Apple Landing Page

A fast, lightweight, and responsive product showcase landing page inspired by Apple's minimalist aesthetic. Built with **React**, **Vite**, and **Tailwind CSS**, this project focuses on high visual impact with zero heavy 3D asset overhead.

## Features

- **Sticky Glassmorphism Navbar:** Smooth, frosted backdrop blur that locks to the top on scroll.
- **Neon Hero Section:** Custom CSS glow background effect framing a high-resolution laptop graphic.
- **Fully Responsive:** Optimized layouts across mobile, tablet, and desktop screens.
- **Performance-Focused:** Zero heavy dependencies or local 3D rendering overhead.

## Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Icons:** Custom SVGs

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Farhad8797/apple-inspired-hero.git
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run the development server:**

   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
